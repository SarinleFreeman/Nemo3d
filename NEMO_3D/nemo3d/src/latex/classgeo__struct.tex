get the relative position vector between two atoms.
\begin{DoxyItemize}
\item Function first will calculate relative atomic position of a1,a2 in a unit cell. If neigbor atom of a2 and atom a2 are in the same unit cell, result is simply the relative posion of atom a1 to atom a2 in a unit cell. Otherwise, function will add +1 or -\/1 to the result, which becomes then relative position of atom a1 in a unitcell to atom a2 in the neighbor unitcell. Normalized result will be converted in a unit of unstraind lattice constant and stored in nnv0.
\item In unstrained environment, all the relative positions of atom X\textquotesingle{}s are same in any unitcells. But once strain starts to affect the structure, the displacements of atoms X due to strain become different with different indice of unitcell. Therefore, we need to get displacement with consideration of cell index of each unit cell. The result in a strained-\/structure will be saved in nnv. ~\newline

\end{DoxyItemize}
